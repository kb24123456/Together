# 悬浮创建器使用根层 Overlay

创建器必须保持独立悬浮卡片，因此使用根视图同层 Overlay 承载，而不使用系统 Sheet，也不再追求 toolbar `+` 到卡片的系统 Zoom 形变。系统 presentation 会把其承载表面纳入转场并产生不需要的 Sheet 外壳或矩形快照；本方案改由卡片和页面暗化层分别执行转场，页面暗化与卡片退出不回弹，卡片入场只允许极轻微的尺度回弹。键盘首次出现后锁定卡片顶部锚点，后续键盘或局部属性 Sheet 的开合不再移动卡片，以优先保证稳定且具有层次的悬浮视觉。日期与时间等局部属性仍可在根层悬浮创建器之上使用独立系统 Sheet，不改变创建器自身的 Overlay 边界。
