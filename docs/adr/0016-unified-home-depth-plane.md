# 首页非活跃界面形成统一背景景深层

待办创建项或详情卡成为活跃对象时，顶部控件、时间线中的其他内容和底部 toolbar 作为同一背景景深层协调变暗、模糊和缩小；正在形变的创建入口、seed、待办创建项或详情卡保持在该层之上。相比只处理任务列表，这一选择需要跨导航 chrome 与时间线协调视觉状态，并明确排除活跃对象，却能让整个首页像一块连续背景平面后退，避免 toolbar 仍保持锐利前景造成层级割裂。

景深层同时表达输入所有权：创建期间背景只接受放弃意图；详情展开期间背景只接受收起意图，点击另一任务主体可转换为最后一次详情切换意图。背景时间线滚动、完成操作、附件操作与 toolbar 动作均暂停，活跃卡内部的编辑和正文滚动不受影响。
