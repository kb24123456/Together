# 完全删除任务模板能力与数据

Together 不再提供任务模板这一产品概念：删除所有模板入口、保存与套用行为、领域类型、repository、依赖注入、持久化模型、测试夹具以及已有模板记录，不保留隐藏入口或兼容服务。相比只移除创建器中的模板选项，这一选择简化了上下文创建与任务模型，却不可逆地放弃用户已保存的模板，并要求在不损伤其他任务数据的前提下完成 SwiftData 与 CloudKit schema 收敛。

新运行时 schema 不再包含模板模型；已发布的 V1 模型定义仅作为升级迁移输入保留，不构成可访问的产品兼容层。迁移删除本地模板记录并尽可能同步云端删除。CloudKit production schema 不允许物理删除已发布 record type，因此允许保留一个没有产品入口、运行时模型或有效记录的空模板 record type 元数据，不为清除该名称而迁移整个 CloudKit container。
