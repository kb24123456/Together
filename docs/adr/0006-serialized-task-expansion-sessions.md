# 任务展开使用串行转场会话

每次任务展开到收回由一个独立且不可交叉的转场会话负责；收起开始后不反转，旧会话的动画、保存任务和回调只能操作自身状态。活跃会话期间的新任务选择采用最后意图优先，当前卡片完整返回并释放后再打开最后选择的任务，从而用少量转场等待换取确定的来源归属、点击响应和清理边界。键盘打开时的关闭仍是一次完整事务，输入提交、键盘退场、卡片返回和会话释放由同一关闭意图触发；保存失败不得让视觉状态停留在半关闭阶段。

关闭意图被接受时必须冻结本会话最后有效的来源几何，保存草稿、完成状态、日期分组或 timeline presentation identity 刷新不得重新决定回程目标。`preparingClose` 与 `closing` 阶段即使 SwiftUI 暂时注销来源行，也应继续回到冻结位置；只有仍处于打开阶段且来源确实被外部删除、或会话从未获得有效来源几何时，才允许使用受控淡出 fallback。
