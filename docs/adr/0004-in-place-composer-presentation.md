# 悬浮创建器采用原位唤醒转场

自 ADR-0011 起，本决策仅适用于定期任务的上下文创建器；待办创建改由时间线中的待办创建项承载。

本决策取代 ADR-0003 的连续呈现进度、顶部切片裁切以及沿屏幕上缘入退场方案，不改变 ADR-0002 的根层 Overlay、固定双区布局和卡内属性编辑语义。

创建器使用 `hidden / mounted / presenting / visible / dismissing` 五个离散阶段。根视图保留正在显示的 route 与草稿初值；关闭时先进入 `dismissing`，待退场完成后才从视图树移除，revision 守卫继续阻止过期 completion 清理新的创建会话。动画状态不得以连续 `CGFloat` 写入 Environment，也不得让整棵创建器视图树逐帧重新计算。

进入时先在最终宽高和最终顶部锚点隐藏挂载，并立即请求标题焦点。卡片整组只使用系统合成友好的 `opacity` 与 `offset`：从最终位置下方 8pt 以约 240ms、无回弹 `.smooth` 淡入归位，不缩放、不使用动态 mask、不逐帧改变阴影半径。类型切换、标题、备注、已有子任务和属性工具栏从同一个离散可见状态派生最多 4pt 位移与透明度级联，级联总时长不超过约 120ms。退出先注销键盘，完整卡片以约 200ms 向下 8pt 淡出。

首页背景只由卡片下方的独立 9% 黑色 scrim 在约 180ms 内淡入淡出，不再对整页执行 blur、saturation、scale 或动画快照。卡片表面、描边和阴影保持静态样式，随整组透明度共同出现。只有 `visible` 阶段允许内部控件命中并进入 VoiceOver 顺序；背景点击与 Escape 关闭能力在整个挂载期保留。Reduce Motion 下取消位移和内容级联，只执行短淡变。

该方案接受不再追求从底部 `+` 到卡片的形变连续性，以换取与键盘上升方向一致的视觉关系、更小的视图更新范围和更稳定的真机帧率。
