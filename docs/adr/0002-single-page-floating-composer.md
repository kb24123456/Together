# 悬浮创建器采用固定双区单页面编辑

自 ADR-0011 起，本决策仅适用于定期任务的上下文创建器；待办创建改由时间线中的待办创建项承载。

保留 ADR-0001 确立的根层 Overlay，但由本决策取代其中的局部属性 Sheet 与缩放入场方案。创建器使用可滚动的正文视口和位于其下方的统一属性编辑区；日期、时间、提醒以及定期属性在同一固定槽位内互斥切换，创建器外层始终预留主按钮空间。无效草稿时内容卡填满该空间，顶部控件与文本保持原位，新增高度只进入中间正文视口，属性工具栏随底边下移；草稿有效后正文视口从底部缩短、工具栏上移、主按钮从卡片后方升起，反向失效时恢复，外层总高度与顶部锚点始终不变。这样既避免整组内容重新居中，也保留明确的状态连续性，代价是应用需要自行维护安全区、自适应高度、内部滚动与无障碍降级。整卡转场继续由根层 Overlay 承载：入场由根层插值呈现进度，卡片组从屏幕上缘移向最终锚点，实体表面在最终布局尺寸内从顶部向下裁切揭示；退场不再反向插值该进度，而是保持完整卡片并使用 `.move(edge: .top)` 沿屏幕上缘整体滑出。背景弱化独立执行，Reduce Motion 退化为短淡变。
