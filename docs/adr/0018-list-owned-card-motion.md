# 首页卡片动效采用列表原位表面与有界跨容器运输

任务详情与待办创建项由时间线中的同一潜伏任务表面持有：列表通过动态占位槽持续拥有顶部、宽度、高度和后续任务让位，首页局部焦点层暂时拥有活跃表面的可见像素，使其不继承背景合成效果。详情保持来源任务顶部和内容列稳定，由表面边界向外、底边向下展开；创建会话先预留最终列表落点，根层 overlay 只运输唯一创建 Seed 到紧凑落点，并在到达列表后原子交还给局部焦点层再向下展开。底部不再使用系统 toolbar，而由根层自定义 Dock 始终持有固定安全区、稳定按钮 Frame 和原生 `Button` / `Menu` 语义；焦点期间只隐藏像素与命中，不改变布局。背景使用单次、克制且保持可读的景深效果，键盘只改变安全可见窗口而不重新决定卡片位置。

详情和创建运输允许从当前形态与速度反向，但详情活跃期间点击其他任务只关闭当前详情，不排队打开新任务；本地持久化提交阶段是唯一锁定冲突交互的阶段。该选择延续 ADR-0009、ADR-0011 与 ADR-0013，取代 ADR-0014 中“关闭后继续展开最后目标”和 ADR-0016 中“bottom toolbar 持续参与统一景深”的决定，并进一步废止本 ADR 早期让系统 bottom toolbar 直接提供运输来源的方案。SwiftUI 负责稳定任务身份、列表占位、内容裁切与根层自有 Dock；根层 overlay 只负责 Dock 到列表紧凑落点的短程 Seed 运输。来源与目标在运输前一次冻结，Seed 不飞向完整编辑高度；Seed / 局部表面 / 持久化列表行通过无 opacity 交叉的原子交接保持每个 presentation frame 只有一个可见实体。若真机与 Instruments 证明 SwiftUI 无法满足精确中断或速度继承，允许仅把 Seed 运输替换为 `UIViewPropertyAnimator`，不恢复窗口级模态详情或长期 UIKit 编辑器。
