# 任务详情使用快照辅助焦点抬升

首页任务详情采用“过渡快照 + 稳定态实时内容”：展开前捕获来源任务行的身份区，由像素一致的快照承载标题、完成框和副标题的焦点抬升；展开稳定后无动画切换为可编辑实时内容，关闭时反向执行。该方案不移动或重挂载真实 SwiftUI 来源行，以避免视图生命周期、手势和状态所有权混乱；也不在运动过程中交叉淡化两套实时身份视图，以消除透明度闪变。

身份快照、实体表面和交互语义必须分层。快照始终使用正常视觉状态且 `opacity = 1`，不能因为动画期间禁止交互而继承 SwiftUI `disabled` 的自动降噪外观；交互由 Overlay 命中和动作守卫控制。来源端点的实体表面透明，前段抬升只改变身份快照的尺度与阴影，卡片表面在开始位移后才渐显；关闭时表面随回程提前渐隐，最终由无表面的身份快照落回列表。这样首尾帧与原列表保持像素和语义连续，不会短暂形成列表中不存在的白色禁用 Cell。

背景景深同样独立于任务身份和卡面：Overlay 的 `UIVisualEffectView` 始终保持 `alpha = 1`，通过一个独立、可暂停和反向的 `UIViewPropertyAnimator` 将 `systemUltraThinMaterial` 从 `nil` 插值到目标效果强度。禁止通过降低整个模糊视图透明度调节强度，因为那会让未模糊的清晰背景按剩余比例直通，最终只像变暗而没有真实失焦。模糊在身份完成前段抬升后建立，关闭时在任务返回来源的移动阶段反向消失；Reduce Motion 只使用较低目标强度。模糊层位于共享身份和卡片下方，不向 SwiftUI 环境传播逐帧进度，也不触发列表重排。
