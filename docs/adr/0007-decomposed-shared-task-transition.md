# 任务详情使用分解式共享转场层

任务行到详情卡的主转场采用窗口级分解式共享层：完成框、标题、备注、子任务进度、时间、提醒和紧急分别拥有稳定身份与起终点，由单一串行会话和 `UIViewPropertyAnimator` 协调，备注使用 Core Animation 裁切遮罩连续揭示，SwiftUI 实时内容只在稳定端点接管。该决策扩展 ADR-0005 的快照辅助焦点抬升，但不再用一张整块身份快照承载所有元素；这样时间、提醒和紧急可以从折叠属性带独立分流到详情底部，同时保持其余身份元素连续，并让关闭可靠返回最新来源。

来源端不存在可见卡片表面，因此共享转场容器不得使用透明承影底板、整行 `shadowPath` 或其他矩形阴影模拟抬升；抬升只由共享元素组约 4pt 的短上移、约 120ms 的独立起步阶段和背景景深表达，稳定共享元素不缩放，卡片实体与卡片阴影必须在共享元素已经离开来源后才建立。详情专属的伴随内容在转场开始前完成目标布局挂载，由卡片边界统一裁切，并在同一个 `UIViewPropertyAnimator` 时间轴内整组轻位移和淡入；禁止再用异步 sleep 或独立 SwiftUI 延迟控制详情揭示。关闭严格反向，并保持伴随内容挂载至回程结束。

完成框、子任务环形进度、时间、提醒和紧急采用稳定视觉边界：转场只插值位置，不插值视觉尺寸、内部布局或裁切范围；标题固定左上对齐，只有多行备注允许使用裁切连续揭示。共享节点必须在不可见状态完成布局后才接管端点画面，避免关闭首帧或末帧发生分批出现、重新居中和裁切。

卡片实体不再从接近屏幕宽度的整条任务行开始，而从任务身份包络生长：包络取完成框、标题实际文字、可见备注和共享属性的外接区域，并增加约 10–12pt 内边距。卡片表面使用独立的中心点、边界尺寸与连续圆角插值扩展到目标卡片，关闭时严格返回同一包络；共享元素位于表面之上，继续遵守稳定视觉边界，不随卡片表面缩放。

每次端点接管前必须经过一次不可见预备布局：来源共享节点先留在原列表位置，覆盖层真正进入 `UIWindow` 后才把实时详情置于最终卡片几何并采集目标 Frame；只有全部可见共享元素都已取得有效窗口坐标后，才能固定 Frame 并启动属性动画。禁止在 `view.window == nil` 时冻结测量结果或用 fallback Frame 充当正常终点，否则动画结束切回 SwiftUI 实时内容时会发生一次整体跳位。返回来源时先恢复真实任务行并等待其完成一个布局周期，再移除处于同一来源几何的共享节点；允许为此增加一个通常为 8–16ms 的不可见准备周期，禁止用未完成布局的节点抢占首帧。

不使用 `matchedGeometryEffect` 作为主转场引擎，因为来源位于可能回收和重排的 `LazyVStack`，目标跨越窗口级 Overlay、内部滚动、键盘与独立属性目的地；这些边界会让纯 SwiftUI 共享几何难以稳定处理多轮展开收起、最终状态回程和会话清理。代价是需要维护多个过渡层及其几何注册，但所有图层必须仍由 ADR-0006 的单一串行会话拥有和释放，禁止各共享元素维护彼此独立的生命周期。
