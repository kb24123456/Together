# 悬浮创建器使用单一可逆呈现生命周期

本决策细化 ADR-0002 的整卡转场，不改变其根层 Overlay、固定双区布局、属性编辑语义或实体表面材质。

创建器由 `hidden / entering / visible / exiting` 四个显式阶段管理。路由负责表达“是否需要创建器”，根视图另外保留正在显示的 route 与草稿初值；关闭时先进入 `exiting`，待约 250ms 的完整退场结束后才从视图树移除。版本号守卫使快速反向操作不会执行过期 completion。

入场只有一个可插值主进度。卡片从第一帧起使用最终宽高和最终内部坐标，顶部锚点在键盘出现前已锁定；整组从屏幕上缘进入，实体表面从约 60pt 的顶部切片向下揭示。类型切换、标题、备注、已有子任务和属性工具栏从该主进度派生轻量透明度与约 4pt 位移级联，不再维护第二套延迟布尔动画。阴影仅改变强度，不逐帧改变模糊半径。卡片稳定后才请求标题焦点。

退场使用独立进度，让完整卡片沿屏幕上缘划出，不反向裁切。背景弱化仍由原页面独立淡出。裁切未完成或退场开始后，内容停止命中并从 VoiceOver 顺序隐藏；创建器仍保留 Escape 关闭动作。Reduce Motion 下取消位移、裁切与级联，仅执行短淡变。

不采用整卡 Liquid Glass、系统 Sheet、Zoom、KeyframeAnimator 或逐行模板动画。实体输入表面继续使用实色，以保证大面积文字编辑的可读性、性能与层级稳定。
