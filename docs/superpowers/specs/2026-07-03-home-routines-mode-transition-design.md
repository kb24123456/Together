# 首页与例行任务同画布转场设计

## 目标

让左上角例行任务入口表现为“切换工作模式”，而不是普通内容替换。网格画布保持稳定，普通任务层、导航标题、例行维度栏与任务行形成有因果关系的连续转场。

## 设计结论

- 保留 `HomeView` 内的同层模式架构，不改为 `NavigationStack` push。
- 左上角循环图标在模式切换时旋转并切换 baby blue 强调色。
- 页面网格背景不移动、不缩放、不闪变。
- 普通任务层退出时轻微缩小、上移、模糊并淡出；例行任务层从下方轻移、去模糊并淡入。
- 例行任务前五行按 20ms 间隔级联出现；返回时按反向顺序收拢。
- 导航标题在“任务 / 例行任务”之间使用 2pt 模糊与淡变替换，不缩放，使用 0.42 秒无回弹 `.smooth`。
- Reduce Motion 下取消缩放、位移、模糊和级联，仅保留 180ms 淡入淡出。

## 架构

- `AppRootView` 负责入口图标、导航标题和根路由状态。
- `HomeView` 同时保留普通任务层与例行任务层，通过状态驱动的视觉 modifier 切换，避免插入/删除视图造成不对称动画。
- `RoutinesListContent` 只负责维度区和任务行的局部级联，不拥有路由状态。
- 动画只读取 `isRoutinesModePresented`，不在动画过程中执行 IO 或数据重排。

## 验收标准

- 进入与退出可以完整反向播放，不出现网格闪烁或内容瞬移。
- 左上角入口、导航标题、维度区和内容层有明确先后节奏，总时长不超过 450ms。
- 快速连续点击不会进入中间错误状态。
- Reduce Motion、动态字体和安全区域行为不回归。
