# 新建任务属性 Chip 自适应显示设计

## 目标

解决新建任务 Sheet 在紧凑宽度下无法单行完整显示全部任务属性的问题，同时保留每个属性的直接入口与已配置值的可见性。

## 展示规则

- 未配置属性只显示 SF Symbol 图标，不显示占位文字。
- 已配置属性显示“图标 + 值”：
  - 日期：`calendar + 今天 / 日期`。当前创建器默认日期视为已配置。
  - 时间：未设置仅显示 `clock`；设置后显示具体时间。
  - 提醒：未设置仅显示 `bell`；设置后显示提醒提前量。
  - 紧急：关闭仅显示 `flag`；开启显示珊瑚色 `flag.fill + 紧急`。
  - 子任务：无子任务仅显示 `checklist`；存在子任务时显示 `checklist + N项`。
- 所有入口保持现有点击行为、禁用规则、清除行为与触觉反馈。
- 不使用横向滚动或两行换行；属性行保持单行，并让各 chip 按实际内容占用宽度。

## 实现边界

- 在共享 `TaskEditorChipSnapshot` / `TaskEditorChipRow` 展示链路增加“是否显示标题”的显式状态，不依赖空字符串猜测业务状态。
- 仅调整新建任务创建器的任务属性快照；例行任务、项目、首页展开态和 OCR 不随本次改动变化。
- 不修改任务模型、保存逻辑或持久化 schema。

## 自适应与可访问性

- 图标入口保留至少 44pt 触控高度与明确的 accessibility label。
- 动态字体下仍保持单行；已配置值允许合理压缩和截断，入口图标不得消失。
- 深色模式继续复用现有主题 token。

## 验收

- 默认新建任务状态能在紧凑 iPhone 宽度单行看到日期、时间、提醒、紧急和子任务五个入口。
- 设置时间、提醒、紧急或子任务后，对应 chip 展开显示值；清除后恢复仅图标。
- `git diff --check`、主 App Swift typecheck、相关测试与 generic iOS `build-for-testing` 通过。
