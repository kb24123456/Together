# Today Task Widget Design

日期：2026-05-04

## 1. 结论

首阶段落地 `Today` 任务小组件。小组件服务于两个目标：在桌面快速查看今天剩余任务，并通过虚线圆角方形完成框轻量完成任务。

首阶段包含 3 个形态：

- 小号 Focus：显示 1 条当前重点任务。
- 小号 List：显示最多 3 条当前未完成任务。
- 中号 List：显示最多 3 条当前未完成任务，阅读与点击空间更舒展。

第二阶段再落地双人模式纪念日小组件，核心方向为头像 + 纪念日计数。第二阶段不和首阶段任务小组件混在同一个实施计划中。

## 2. 目标

- 让用户不打开 App 也能知道今天还剩几项。
- 让用户能从桌面直接完成清晰可识别的任务。
- 让小组件与 App 内 `Today` 保持一致，不新增另一套任务优先级。
- 延续当前 Together 的干净留白、轻层次、弱阴影、低饱和配色和中文效率工具语气。
- 为后续双人纪念日小组件预留独立阶段，但不拉高首阶段交付复杂度。

## 3. 非目标

- 不在小组件内创建任务或输入任务。
- 不做 Widget 专属排序、筛选、清单配置或项目配置。
- 不让小组件跟随 App 当前选中的非当天日期；小组件固定展示“今天”。
- 不在首阶段实现双人纪念日小组件。
- 不把旧双人协作语义扩散到任务小组件。
- 不在 widget 内展示复杂错误状态。

## 4. 产品形态

### 4.1 小号 Focus

用途：让用户只关注下一件最该做的事。

内容：

- 顶部：`今日`。
- 顶部右侧：`还剩 N 项`。
- 主体：Today 当前排序下第一条未完成任务。
- 任务行：左侧虚线圆角方形完成框，中间中文任务标题，右侧显示截止时间。
- 无截止时间时，右侧不显示时间；任务标题区域保持和有截止时间的行对齐。

交互：

- 只有虚线框触发完成任务。
- 标题、时间、背景和空白区域都进入 App 的 Today。

### 4.2 小号 List

用途：在小尺寸里直接处理最多 3 条 Today 任务。

内容：

- 顶部：`今日`。
- 顶部右侧：`还剩 N 项`。
- 主体：最多 3 条 Today 当前排序下的未完成任务。
- 三行任务等高铺开，避免底部多余留白。
- 每行包含左侧虚线圆角方形完成框、中文任务标题、右侧截止时间。

边界：

- 当前目标形态是 3 行。
- 如果真实 Widget Preview 中中文长标题、动态字体或点击区域明显挤压，则降级为最多 2 行。
- 不保留“点击进入今日”的单独提示区；空间优先给任务。

交互：

- 只有虚线框触发完成任务。
- 任务标题、截止时间、背景和其他空白区域都进入 App 的 Today。

### 4.3 中号 List

用途：提供更舒展的 Today 前 3 条任务处理入口。

内容：

- 顶部：`今日重点`。
- 顶部右侧：`还剩 N 项`。
- 主体：最多 3 条 Today 当前排序下的未完成任务。
- 每行包含左侧虚线圆角方形完成框、中文任务标题、右侧截止时间。

与小号 List 的区别：

- 数据语义相同，都是 Today 未完成任务前 3 条。
- 中号的价值在于更好的中文可读性、更舒服的完成框触控、更清晰的截止时间展示。
- 中号不强化单独的“第一重点任务”视觉层级，避免和 Today 当前排序产生额外解释成本。

## 5. 任务选择规则

小组件沿用 App 内 Today 当前排序。

规则：

- 小号 Focus 取 Today 当前排序下第一条未完成任务。
- 小号 List 取 Today 当前排序下前 3 条未完成任务。
- 中号 List 取 Today 当前排序下前 3 条未完成任务。
- 今日未完成任务少于可展示行数时，只显示实际数量。
- 今日没有未完成任务时进入空状态。

不新增 Widget 专属优先级规则，不新增用户配置入口。

## 6. 完成交互

### 6.1 触发范围

只有左侧虚线圆角方形完成框是完成按钮。

非完成区域包括：

- 任务标题。
- 截止时间。
- 小组件背景。
- 行内空白区域。

这些区域统一 deep link 到 App 的 Today。

### 6.2 动画反馈

完成任务走乐观反馈：

1. 用户点按虚线框。
2. 完成框显示勾选反馈。
3. 对应任务行淡出并上移消失。
4. 后续任务补位。
5. App Intent 写入完成并请求 WidgetKit reload。

失败策略：

- 如果完成写入失败，不在 widget 内展示复杂错误。
- 下次 timeline reload 后任务会按真实数据恢复出现。

Reduce Motion：

- 开启 Reduce Motion 时，不依赖复杂位移动画。
- 完成框短暂显示勾选态后直接刷新任务列表。

## 7. 空状态

当今天没有未完成任务时，小组件显示完成态。

内容：

- 文案方向：`今日已清空`。
- 辅助文案方向：`享受当下，或规划新任务`。
- 插画：复用 Today 当前空状态插画视觉；当前代码中 Today 空状态使用 `EmptyCalendar` 资产，若后续 Today 插画替换为猫咪插画，小组件跟随 Today 空状态视觉更新。
- 点击空状态任意非按钮区域进入 App 的 Today。

不在空状态中提供 widget 内输入。

## 8. 技术架构

### 8.1 Widget Extension

新增 Widget Extension 承载：

- WidgetKit timeline provider。
- 小号 Focus 渲染。
- 小号 List 渲染。
- 中号 List 渲染。
- 空状态渲染。
- Widget Preview。

### 8.2 App Group Shared Store

App 主进程负责把 Today 当前排序结果写入 widget 专用快照。Widget 只读快照，不直接读取完整 App 运行态。

快照字段：

- `remainingCount: Int`
- `tasks: [TodayWidgetTaskSnapshot]`
- `taskID: UUID`
- `title: String`
- `dueTimeText: String?`
- `sortIndex: Int`
- `deepLink: URL`
- `snapshotUpdatedAt: Date`

快照只存显示和交互所需字段，不写敏感信息。

### 8.3 App Intent

新增 `CompleteTodayWidgetTaskIntent(taskID:)`。

职责：

- 根据 `taskID` 完成任务。
- 复用现有任务完成服务或共享完成入口。
- 成功后写入最新 widget 快照。
- 请求 WidgetKit reload。

App Intent 只处理完成任务，不承载创建、编辑、排序或筛选。

### 8.4 Deep Link

小组件非完成区域进入 App 的 Today。

首阶段不要求直接进入任务详情，避免路由复杂度和状态恢复成本。后续如果需要，可在第二轮扩展为点任务标题进入任务详情。

## 9. 刷新策略

App 主动写快照，WidgetKit 轻量 reload。

刷新时机：

- App 启动并加载 Today 后写入 widget 快照。
- Today 任务创建、完成、重新打开、删除、排序变化后写入快照。
- App Intent 完成任务后写入最新快照并请求 reload。
- App 不在运行时，widget 使用最近一次快照。
- 快照过旧时显示弱提示方向：`打开 App 更新今日`。

Widget 固定展示今天，不跟随 App 当前选中的非当天日期。

## 10. 设计语言

方向：

- 中文优先。
- iOS 原生感。
- 干净留白。
- 轻层次。
- 弱阴影。
- 低饱和强调色。
- 黑 / 白 / 粉只作为品牌强调，不做甜腻或高饱和装饰。

完成框：

- 复用当前列表里的虚线圆角方形完成框语言。
- 视觉基础来自现有 `SubtaskCheckbox` / routines / project completion badge：`RoundedRectangle` + dashed `StrokeStyle` + coral checkmark。

不显示剩余百分比，只显示剩余任务个数。

## 12. 第二阶段：双人纪念日 Widget

第二阶段单独设计和落地双人纪念日小组件。

当前已确认方向：

- 仅在双人模式有效。
- 核心信息是头像 + 纪念日计数。
- 复用当前重要日期 / 纪念日规划规则。
- 单人模式、无双人空间或无纪念日时显示合理空状态。

第二阶段需要单独收敛：

- 展示哪个纪念日：固定 anchor、用户手动选择、还是沿用 Today 重要日期胶囊 planner。
- 头像展示：双方头像叠放、左右并列或中心组合。
- 计数语义：已经 N 天、还有 N 天、还是根据日期类型自动切换。
- 支持尺寸：小号优先，是否需要中号。
- 是否支持点击进入重要日期管理页。

## 13. 验证标准

首阶段完成后必须验证：

- `xcodebuild build -project Together.xcodeproj -scheme Together -destination 'generic/platform=iOS' -quiet` 通过。
- Widget extension 编译通过。
- 小号 Focus、小号 List、中号 List Preview 能展示正常态。
- Preview 覆盖空状态。
- Preview 覆盖长中文标题。
- Preview 覆盖有截止时间和无截止时间。
- 虚线框完成任务后，widget reload 后任务消失。
- 点击非完成区域能进入 App Today。
- Reduce Motion 下不依赖复杂动画表达完成。

当前项目记忆要求后续不做模拟器测试；本阶段默认只做 `generic/platform=iOS` 编译与 build-for-testing，除非用户重新要求模拟器验证。

## 14. 风险与边界

- 小号 List 三行中文任务存在可读性和点击密度风险；真实 Preview 如果挤压，需要降级到两行。
- Widget App Intent 的完成逻辑需要复用应用层服务，不能另写一套绕过同步和状态机的完成逻辑。
- App Group 快照必须和 Today 当前排序一致，否则用户会看到 App 与 widget 优先级不一致。
- 旧快照可能过期；过期状态只能弱提示，不应阻塞 widget 展示。
- 第二阶段双人纪念日 widget 不进入首阶段实现计划，避免任务小组件交付被双人数据边界拖慢。
