# 多方向随机注视 · 2026-09-09

用户真机反馈：上一版只是增加左右转向，希望随机不同方向、更自然、有生命感。本轮已更新 Rive 编辑源、运行文件与 App 打包资源；未改 Swift 展示逻辑、15 秒打盹条件、编辑位置、书写/流汗表情或静态降级图。

## 当前观感与选择方式

每次从有限的预制注视中随机选择，包含上、下、左上、右上、左下、右下。转向时横纵轴错开几帧，形成轻微弧线；看过去后停留并作一次小幅纠正，再自然回到共同姿势。方向、移动时长、停留和眨眼相位有所不同，不使用逐帧随机噪声。

| 动作 | 方向 | 总时长 |
| --- | --- | --- |
| Idle | 左上 | 6.4 秒 |
| Idle_QuietMedium | 右下 | 5 秒 |
| Idle_GazeUp | 上 | 4.4 秒 |
| Idle_GazeDown | 下 | 4.8 秒 |
| Idle_GazeUpRight | 右上 | 5.6 秒 |
| Idle_Look | 左下短瞥 | 1.6 秒 |

首次出现与休息之后从五种主要注视中等权选择，每种 20%；首次转向约 0.77–1.78 秒开始。主要注视之后，80% 进入原有 3.6 秒呼吸/眨眼休息，20% 插入一次左下短瞥再休息。没有固定左右轮流，也不会直接连续播放相同片段；隔着休息再次选中同方向仍是合法随机结果。

共同首尾沿用既有 neutral yaw=0.15 / pitch=0.2，避免破坏书写、逾期、思考和唤醒接口；主要注视点覆盖完整上下与斜向。三个新增片段复制全部中断条件和附属部件隐藏，仍是单层状态机和原有业务模式，不增加 App 输入或逐帧计算。

## 在 Rive 中查看

当前编辑文件仍为教育空间副本 [Together Sphere Motion Study](https://editor.rive.app/file/together-sphere-motion-study/2564580)，主画板 `TogetherSphere`。

- 播放 **Mascot**：观察实际随机选择，`mode=0`。Rive 单独预览没有 App 的 15 秒计时器，可连续观察。
- 播放 **Idle_Orient**：27.8 秒串联上、右下、右上、下、左上、左下，便于逐一比较；这是固定校样顺序。
- **Preview_All**：同步其中原有 Idle 和 Idle_Look 段，其他表情段保留。
- `assets/`：六个方向在驻留帧的原生 PNG 捕获，无位图后期编辑。

当前为 **33 条时间轴、32 个状态节点、141 条转场**；17 个模型属性、12 色和 29 个颜色绑定目标不变。时间轴数量包含逻辑和预览，并不等于表情数量。
