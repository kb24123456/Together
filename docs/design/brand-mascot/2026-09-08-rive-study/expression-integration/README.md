- 新表情沿用 `SphereEyeNear` / `SphereEyeFar` 每眼 8 个三次贝塞尔顶点的同一套球面眼形。单眨眼近侧眼保持胶囊，远侧眼闭成圆润的上拱弧；流泪从中性眼闭合，泪水贴近眼部并随朝向改变宽度与曲率，结束后恢复。
- `IdleFace`（0-19）下新增 `TearFlows`（0-185826）及两行泪水，和球面眼共用显隐层级。原 26 条时间轴既有关键帧未修改，只新增 52 个泪流组 opacity=0 保护关键帧，避免旧片段残留泪水。
- 原 `Mascot` 路由、转场与动作规范保留。本轮开始时 `Behavior` 层停用，已将 flags 属性 754 从 1 恢复为 0；随后原生 300 帧常驻 → 书写 → 流汗 → 常驻检查通过，共 11 次转场。
- 本次整合阶段只制作片段；后续操作接线已将原 `Acknowledge` 状态指向单眨眼。流泪仍未接自动路由，不能把逾期或失败直接解释为流泪触发场景。
- 当前主题增加 `tearColor`，浅色黑球为 `#88CFF3`，深色白球为 `#347FA6`。同一实例现有 12 个颜色属性驱动 26 个颜色目标，完整当前配置见 [theme-integrated.json](theme-integrated.json)；原 `theme-v6.json` 是 11 色历史基线，不覆盖新增泪色。

- [显示校样与静态素材](../../2026-09-08-display-review/README.md) 已包含常驻、持笔、思考、担忧、开心、单眨眼、流泪、打盹，两主题共 16 张 PNG。31 项静态检查通过；5 组 375 / 402 CSS 像素宽度的浏览器视觉检查未发现选定组合中的裁切或标题遮挡，编辑页取消和保存按钮保持清楚。仅检查列出的组合，不宣称所有姿势、尺寸、主题已穷举视觉验收。
