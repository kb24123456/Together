用户随后否定首版的细手臂和只增加汗滴的表达：要求仅保留圆形手部；如果确需手臂也不能太细。流汗时眼睛必须对应变化，汗滴贴近面部。

第二版通过内置 image_gen 编辑首版三姿态图，同时附加已认可默认球体作身份参考；实际 PNG 文件头仍为 1672×941，原图未做后处理。视觉检查：已去除可见细手臂，手部变成圆球形；担忧状态的两只眼睛已相对静候改变倾斜，汗滴移到脸侧并与黑色球体边缘相接。默认身体的完整圆度和大眼风格保留。小尺寸表现仍待验证，不能将设定图当作真实 40pt 验收。

用户继续反馈：第二版手和汗滴仍太小，书写应参考[蓝色团子的折线眼](reference-focused-dango.png)，表达认真、用力和专注；流汗更着急，参考[漫画线条五官](reference-manga-expressions.png)。第三版虽放大手和汗滴，但增加眉毛、空心眼圈和嘴巴，随后被评价为浮夸、复杂。

最新约束：五官最多两条眼睛线，可以弯曲，不要明显眉毛、嘴巴或额外表情线；泪水等辅助元素可以使用。主体与静候大白眼继续保留。

第四版用内置 image_gen 编辑第三版，实际输出经文件头验证为 1672×941 PNG，未后处理。手为放大的完整圆球，没有细手臂；眉毛、眼圈与嘴巴已移除，但动作眼形随后被用户否定。

后续反馈：用户评价第四版眼睛线条丑陋；第五版尝试圆润收窄，但生成结果再次缩成短小眼形，未采用。用户随后明确表示除“第一版”满意的风格外，生成的书写/着急方向均很丑。所有这些动作眼形均不作定稿；“第一版”具体指代仍待确认，不擅自猜成某一张图片。

第六版反馈：用户已认可右侧流汗表情，仍否定当时的中间书写表情。右侧两条向内挤压的闭眼线与大贴脸汗滴作为保留基准。后续只修正书写的两条眼线，保留球体、大圆手和笔，不重新探索已认可的流汗形象。

第七版：只修改中间书写眼睛，移除折角与竖直尾段，改为两条内侧稍压低的圆端眼线；右侧流汗沿用已认可方向，并单独保留第六版原图作为基准。用户重新附图并评价“这一版接近我需要的方向”，进一步明确“书写表情还需要更专注”。第七版作为当前方向基准，不继续探索新的眼形体系。

第八版：只进一步压低书写眼线内侧、略收紧眼距，加强视线向写字区域聚拢的感觉；仍保留两条圆端连续眼线，无新增五官。用户表示“基本满意”，以此作为静态设计基准，眼形无需继续微调。
