## 设计判断

建议采用一次克制的 wink，表达“收到，已经改好了”。点头会增加整体位移；双眼微笑偏向情绪表达；勾号更明确，但会改变现有角色的面部语言。具体操作结果仍由文字说明，wink 不单独承担任务完成状态的含义。

胶囊保持原有高度，表情在左侧；靠近文字的眼睛闭合，另一眼保持不动。眼型比例参考现有 MascotIdle 与 MascotWink 素材，使用连续矢量路径演示，不以两张图片交叉淡变替代形变。

- 动作共 380ms：闭合 100ms、停留 80ms、睁开 200ms。
- 与胶囊展开的末段重叠，不增加反馈前的等待。
- 每次展开一次，结果停留时恢复清醒。
- 减少动态效果时保持睁眼，静态显示结果。
