已取得教育空间运行文件与备份，前版 Apple runtime 资产检查、最小 iPhone 接入与无签名测试构建已通过。`2026-09-09-refinement` 新资源与布局也已完成独立资产检查及最终整合构建，下一步从当前源码签名安装验收真机；教育计划用途不能自动扩为商业开发/发布。

开始时要知道哪些部位需要动，并画出三个关键姿势；不需要一开始就制作所有部件和关键帧。PNG 参考图可导入 Rive，但整张图不自带独立的眼睛、手、笔、遮挡关系或状态机。本角色以简单几何为主，推荐在 Rive 中重建矢量，或导入分组明确的 SVG；不以逐帧生成的 PNG/GIF 作为生产动画。

| App 情况 | 角色表现 | 退出规则 |
| --- | --- | --- |
| 首页可见、无当前逾期 | 静候，轻呼吸和间歇眨眼 | 进入编辑或出现逾期 |
| 创建/编辑页可见 | 拿笔等候；发生输入后书写 | 输入停顿则持笔，页面关闭则退出 |
| 非编辑状态且有当前逾期 | 轻微担忧，偶尔汗滴 | 当前逾期归零时恢复 |
| 编辑中同时有逾期 | 编辑动作优先 | 离开编辑后重新取当前逾期状态 |
| 非编辑且有真实处理过程 | 托脸思考 | 处理结束时读取最新目标 |
| 合法的真实任务完成 | 一次轻庆祝；仍有逾期时先恢复眼形 | 合并反馈，结束后读取当前目标 |
| 常驻且已有适合的轻提醒事件 | 一次克制抬手 | 不排队，去重和冷却由 App 负责 |
| 可见、无更高目标且无操作 15 秒 | 睡眠眼弧与三个渐大浮起淡出的 Z | 滚动/减速保持清醒，结束重新计时；用户操作、编辑/处理均可唤醒 |
| 页面不可见或 App 非活跃 | 暂停对应实例 | 可见且活跃后用最新状态恢复 |
| Reduce Motion | 对应静态姿势 | 不运行呼吸、摆动、持续书写循环 |
| 资源加载失败 | 静态角色 | 保持原生按钮和任务操作可用 |

已实现的 Rive 契约：mode=0/1/2/3/4 分别为常驻/编辑/逾期/真实处理/可见打盹；isTyping 和 celebrateRequested 为布尔，acknowledge 与 remind 为 trigger。完成事件仅适用于目标 mode=0/2，编辑/处理/打盹/隐藏时取消待播请求。完整优先级、退出中合法完成、FeedbackDone 收尾及 Host 冷却边界以 operation-mapping-v6.md 为准。Reduce Motion、可见性暂停、浅深色及 Apple runtime 已接入，待真机验证。

App 负责业务判断、优先级与输入活动合并；Rive 负责姿势、关键帧、混合和过渡。不把任务文本、日期算法或数据库操作放进动画文件。持续状态用属性；完成反馈只来自真实成功操作，普通保存、同步和历史重新显示不能触发。进入编辑/处理/打盹需取消待播完成；所有动画都不阻塞业务操作。

输入停顿阈值可从约 `0.8–1.2s` 开始视觉调试；当前 Rive 呼吸采用约 `0.55–0.65%` 等比幅度、3.6 / 5 / 6.4 秒静候片段。这些是建议起点，不是已验收参数。输入只更新轻量活动状态，不逐字重载 Rive 文件或重启动画。

逾期首版建议沿用普通待办的真实当前时间语义，区分精确时刻和纯日期；不把定期任务错过次数直接当普通逾期，也不让浏览历史日期改变角色的“当前”情绪。截止时刻、跨午夜、前台恢复和任务完成/改期时刷新派生状态，避免只在数据库变化时刷新而漏掉时间自然推进。
